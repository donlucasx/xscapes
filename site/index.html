a thinking screen for terminal agents

xscapes

Your terminal agent works inside a small ASCII landscape. The scene moves with the work, and the companion who lives there knocks when the agent needs you.

You send a prompt and the terminal goes quiet. Agents now think for minutes at a time, and that time has no face. xscapes gives it one.

Each landscape is a scape. The first one is a shoreline: a sea that rises while the agent thinks, the last few actions written in the sand, and a cat who sits with you until it is done. Everything on this page is that scape, running.

  • A glance is enough. How hard it is working, what it is doing right now, whether something broke, whether it is waiting on you. Nothing to read.
  • Two knocks you can tell apart from across the room. A solid balloon and a chime when it needs you, a dotted one and a low note when it is done. Silent while it works.
  • It lives where the agent lives. The same window, no browser tab, nothing to configure, and the agent's own screen untouched.
  • One fact, one place. Activity, subagents, finished todos, context left: each owns its own part of the scene. On the shore those are the swells, the kittens, the stars and the moon.

Fourteen seconds into a turn, at noon. Edits landing, five subagents out, the sand carrying the last tool calls. Every clip on this page is the real engine folding the same events the Claude Code adapter emits. Nothing is posed.

go install github.com/donlucasx/xscapes@latest
xscapes install claude --apply  # Claude Code: writes its hooks after a backup, uninstall restores them byte for byte
xscapes claude  # the agent in the top of the window, the scape underneath
xscapes inside <any command>  # anything else: host it the same way

It runs on your clock

The scape keeps the time of day where you are. There is no theme setting and no dark mode switch: the sky goes dark because it is dark outside, the sun crosses it, and the light on the water follows. You look up from your work and the landscape has moved on with the afternoon, the way one outside the window would.

Below is one session at four hours.

Afternoon. A command exited 1. The companion carries it, ears back and tail flat, until you come back. The weather never does.

Dusk. The agent needs permission. A solid balloon, the alert pose, and a chime.

Night. Done, every todo lit. A dotted balloon and a low note. The moon has waned and sunk with the context, and the number under it says what is left.

Dawn, half a minute later. Flat sea, the writing receding, the companion dozing.

What a glance tells you

Everything on screen means one thing, and no two things share a channel. The water is the work. The sky is the world. What follows is the shoreline's vocabulary; a different scape spends the same channels on its own scenery.

how hard the agent is workingthe sea: how many swells are travelling, how tall, whitecaps above half
what it is doing right nowwriting in the sand: newest brightest, older lines taken by the tide
something is brokenthe companion: ears back, tail flat, amber eyes, until you come back
it needs youa solid balloon in a warm colour, plus a bright chime
it finisheda dotted balloon in a cool colour, plus a low sonar note
subagentskittens, one per agent, on the sand or in the water; they swim off when they finish
todos completedstars in the upper sky, one lit per finished item
context leftthe sun by day, the moon by night: it wanes and sinks as context is used, with a number under it from 40% used
time of daythe sky, from your actual clock

Sea state always means the agent. Sky, light and time always mean reality. You never have to ask which of two meanings a change is carrying.

Underneath, a protocol

xscapes is two things. Below is an event protocol with pluggable adapters, which works for any agent that runs in a terminal. On top are the scapes, which are what that protocol looks like once you give it a landscape and something living in it.

session_start  prompt  tool_start  tool_end  error  test_pass  test_fail  sub_start  sub_end  needs_input  done  compact  context  todo  session_end

Tool events do not each get their own weather. Every one feeds a single activity level, and the sand names the tool and the file. The sea says how much, the sand says what. Claude Code is wired through its hooks, and xscapes emit needs_input -text "allow Bash?" from a shell script is a complete adapter for anything else. If an agent can run a command, it can drive a scape.

A companion for the session, not a toy for the task

It runs for the whole session. Tasks move the scene and the day passes over it. The same repository always gets the same shoreline, seeded from its git root, and the companion is yours across all of them. One Go binary, no dependencies, every colour an xterm-256 index, so it looks the same in Terminal.app, iTerm2 and Ghostty. Running daily. The next landscapes and companions are drawn and waiting to be picked.
