xscapes

A thinking screen for terminal agents. Claude Code runs inside a shoreline: the sea rises while it works, the sand records what it did, and a cat knocks when it needs you.

One Go binary, no dependencies, any 256-colour terminal. MIT. github.com/donlucasx/xscapes

Fourteen seconds into a turn, at noon. Edits landing, five subagents out, the sand carrying the last tool calls. Every clip on this page is the real engine folding the same events a Claude Code hook emits, drawn as a 256-colour terminal draws it. Nothing is posed.

go install github.com/donlucasx/xscapes@latest
xscapes install claude --apply  # writes the hooks after a backup; uninstall restores byte for byte
xscapes claude  # Claude Code in the top of the window, the shoreline underneath

Why

You send a prompt and the terminal goes quiet. You tab away and forget to come back, or you sit and watch a spinner that says nothing. Agents now think for minutes at a time, and that time has no face.

xscapes gives it one. A glance at the window tells you how hard the agent is working, what it is doing right now, whether something broke, and whether it is waiting on you. Nothing to read, nothing to configure, and the agent's own screen is untouched.

What a glance tells you

Everything on screen means one thing, and no two things share a channel. The water is the work. The sky is the world.

how hard the agent is workingthe sea: how many swells are travelling, how tall, whitecaps above half
what it is doing right nowwriting in the sand: newest brightest, older lines taken by the tide
something is brokenthe companion: ears back, tail flat, amber eyes, and it stays that way until you come back
it needs youa solid balloon in a warm colour, plus a bright chime
it finisheda dotted balloon in a cool colour, plus a low sonar note
subagentskittens, one per agent, on the sand or swimming in the water, and they swim off when they finish
todos completedstars in the upper sky, one lit per finished item
context leftthe sun by day, the moon by night: it wanes and sinks as context is used, and a number appears under it from 40% used
time of daythe sky, from your actual clock

Sea state always means the agent. Sky, light and time always mean reality. You never have to ask which of two meanings a change is carrying, and that is why a glance is enough.

A command exited 1. The companion carries it, ears back and tail flat, until you come back. The weather never does.

Dusk. The agent needs permission. A solid balloon in a warm colour, the alert pose, and a chime.

Night. Done, with every todo lit. A dotted balloon in a cool colour and a low note. The moon has waned and sunk with the context, and the number under it says what is left.

Dawn, half a minute later. Flat sea, the writing receding, the companion dozing.

Two knocks

"I finished" and "I am blocked on you" are different messages and never look the same. The two balloons differ in shape as well as colour, so they survive a screenshot and a colourblind reading, and they carry different sounds, so they survive you looking at another window. Silent while the agent works, and each rings once.

It lives where the agent lives

No browser tab, no second window, nothing to alt-tab to. The agent gets the top of the window and the shoreline reads downward from it: sky, sea, beach. A taller window spends its extra rows on beach, where the work is written. The agent runs on its own pty, held in a scroll region, and its bytes reach your terminal untouched, so nothing xscapes misreads can corrupt its display. Every colour is an xterm-256 index, so the picture above is the picture you get, in Terminal.app, iTerm2 or Ghostty.

Underneath, a protocol

xscapes is two things. Below is an event protocol with pluggable adapters, which works for any agent. On top is one reference scape, which is what that protocol looks like when you give it a sea and a cat.

session_start  prompt  tool_start  tool_end  error  test_pass  test_fail  sub_start  sub_end  needs_input  done  compact  context  todo  session_end

Tool events do not each get their own weather. Every one feeds a single activity level, and the sand names the tool and the file. The sea says how much, the sand says what.

  • Claude Code, via hooks. One command installs them after a backup, merging with the hooks you already run. The payload schema was read out of the Claude Code binary, not guessed.
  • Anything else: xscapes emit needs_input -text "allow Bash?" from a shell script is a complete adapter.

A companion for the session, not a toy for the task

It runs for the whole session. Tasks move the scene and the day passes over it. The same repository always gets the same shoreline, seeded from its git root, and the companion is yours across all of them. Three interactions, one keypress each, and it never becomes a game.

Where it is

Running daily. The shore, the Claude Code adapter, both knocks with their sounds, the kittens, the context readout and the launcher all work in Terminal.app and Ghostty. Next: a 60-second recording of a real turn, the campsite and the rainy window, and an adapter for any process.
