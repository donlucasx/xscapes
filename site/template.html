xscapes

a thinking screen for terminal agents

↓

Cozy ASCII scenes that react to your agent while it works

Every character below is a fact about the agent — not a filter over a picture. The page is drawing what your terminal draws.

One whole session. The agent works in the top rows exactly as it always has; underneath, the sea comes up with the work and settles when it stops, a crablet arrives for each subagent and walks into the water when that one reports back, stars light as the plan gets done, and the moon sinks as the context fills. The day turns underneath the whole time, on your real clock — which is why nothing else in the scene has to carry the hour.

$ go install github.com/donlucasx/xscapes@latest $ xscapes install claude --apply # writes its hooks, after a backup $ xscapes claude # the agent on top, the scape underneath $ xscapes inside <any command> # anything else, hosted the same way

The same beach in five moments. Press one and only the thing that carries it changes — that is the whole language, and it is why you never have to read the screen.

Hero the crab ships as the default. The cat came first, and is one command away — a scape that is already running picks the change up on its next frame, without restarting your session.

$ xscapes companion cat

A landscape only needs six things to carry the whole system: a light, a sky, something that moves with the work, a surface, somewhere the work piles up, and someone living in it. So there is no reason to stop at one.

The rainy window, with the cat. Rain on the glass carries the work and comes down harder the busier your agent gets. The city behind it carries the hour, and the sill is where the day's work settles.

The aquarium, with the frog. More fish come out as the work picks up, the tank's lamp is the light, and the gravel is where it settles. Water is the work again, for the same reason it is on the shore.

The scene is one implementation. Underneath it is a small event protocol and a thin adapter for each agent, which is the part that outlives the shoreline.

  • Any agent, any terminal. Claude Code arrives already wired. Anything that can run one command can drive the scene.
  • One fact, one place. Activity, subagents, finished work, context left: each owns its own part of the picture, and nothing shares a channel. That rule is why a glance is enough.
  • Two knocks you can tell apart from across the room. A solid balloon and a chime when it needs you, a dotted one and a low note when it is done. Silent while it works.
  • The same picture everywhere. It draws in the 256 colours every terminal agrees on, so what you see here is what you get.
