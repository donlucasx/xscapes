xscapes

The waiting layer for terminal agents.

An event protocol, pluggable adapters, and one reference scape.

Commons · Make Waiting for AI FunSeptember 2026

Waiting for an agent is dead time.

You send a prompt, the terminal goes quiet, you tab away, and then you forget to come back. Agents now think for minutes at a time, and that time has no face.

xscapes02
xscapes

Your agent runs inside a shoreline. The sea rises while it works, the sand records what it did, and a crab knocks when it needs you.

  • A glance is enough. How hard it is working, what it is doing, whether something broke, whether it is waiting on you.
  • Two knocks you can tell apart from across the room, each with its own sound. Silent while it works.
  • It lives where the agent lives. The same window, nothing to configure, the agent's screen untouched.
  • Subagents are crablets, context is the moon. Every fact about the session has its own place, and no two share one.
xscapes03

What a glance tells you

Nothing to read, nothing to configure, and the agent's own screen is untouched.

how hard it is workingthe swells: how many are travelling, how tall, whitecaps above half
what it is doing right nowwritten in the sand, newest brightest, older lines fading as the tide takes them
something brokethe companion, not the weather: claws down, pulled in small, amber eyes, until it clears
context remainingthe moon: it wanes and sinks as context is used, with a number under it from 40% used
it needs youa knock and a sound, and a different one for done

The water is the work. The sky is the world.

One variable per perceptual channel. Nothing crosses. Encoded in coverage, count or position, never in rate, because a glance is the entire budget and a screenshot has no motion.

xscapes05

The nudge has to beat a terminal bell.

Dusk. The agent needs permission. A solid balloon, a warm colour, a chime. Done is a dotted balloon, a cool colour, a low note. Two cues you can tell apart from across the room, and each rings once.

Underneath, a protocol. Any agent that can emit ten events gets every scape.

tool carries a kind: read, write, edit, search, shell, web, subagent, todo, mcp

→

engine

A Unix socket, with a JSON-lines file as the fallback.

One reducer turns the stream into a level, a tail, a pose, a bubble.

Recordings replay offline, so the mapping is tuned on real sessions, not on a demo.

→

scapes

Shore shipped

Campsite, rainy window: next. Each fills six slots: light, sky, motion, surface, accumulator, companion.

adapter · Claude Code hooks shipped

Installed with one command. Your settings are merged, not replaced, and the uninstall restores them byte for byte.

adapter · any process next

Busy means alive and printing; done means the prompt is back. Enough for agents with no hooks at all.

xscapes07

One Go binary. No dependencies. Any 256-colour terminal.

Every colour is an xterm-256 index, so the picture is the same on every terminal and every profile. Terminal.app, iTerm2, Ghostty.

The agent runs in the same window, no tmux. Claude Code arrives wired; anything that runs one command can drive the scene. The older side-by-side layout is one flag away.

xscapes08

Built against measurement, not against a demo.

Every visual claim was checked on the rendered frame, not on what the source says it should do.

13,682

tool events from real Claude Code sessions, recorded by the hooks and folded through the reducer offline to tune what the sea does.

48

half-hours of sky and sea measured on the rendered frame, so the gradient bands were counted, not eyeballed.

43%

of "notification" hooks turned out to be a 60-second idle nag, not a request for input. Measured on 12,809 events, and the adapter tells them apart.

xscapes09

A companion for the session, not a toy for the task.

  • It runs for the whole session. Tasks move the scene; the day passes over it.
  • The same repository always gets the same shoreline, seeded from its git root. The companion is yours across all of them.
  • Three interactions, one keypress each, and it never becomes a game. Pet the companion, plant a tree, skip a stone.
  • Next: the campsite and the rainy window, an adapter for any process, and a browser gallery for people who will not install a binary. All MIT, public since day one.
